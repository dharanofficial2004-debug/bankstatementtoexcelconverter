# French keyword map — before implementation

Date: 2026-09-27. All 11 existing French routes inspected, including their imported presentation components, route layouts, root metadata, robots and sitemaps. No pages created. No redirects or merges planned. Keywords are an editorial intent map, not measured keyword volumes. No Search Console or backlink data was available.

## Cannibalization decision

Ten pages currently overlap on conversion/extraction; CSV already has a genuine format-specific intent but its copy still overlaps. `/fr/convertisseur-releve-bancaire-excel` has the strongest existing depth and is an alternative consolidation candidate. We select `/fr/convertir-releve-bancaire-en-excel` as the main general Excel URL for its clear user-facing purpose, without claiming ranking authority. Grammatical/accent variants belong there. All other overlapping URLs receive distinct, substantive user tasks rather than synonym targeting. Historical slugs are retained. No canonical consolidation, merge, deletion or redirect is performed. If organic data later supports consolidation, reassess the five old Excel-slug guides rather than keeping thin alternatives.

## Findings before editing

- Shared Navbar/Footer/Hero/VideoDemo introduce English labels and HDFC/UPI examples. Hero CTA links to the existing /app; no converter is embedded on French routes.
- Ten detail routes advertise guessed English equivalents formed by removing /fr; these are not actual counterpart routes. Root FR/EN alternates are not reciprocal. Spanish and Portuguese bank hubs are not exact translations of the proposed focused guides.
- Root Open Graph and Twitter metadata are English. Root title template adds the brand to each existing title.
- All French routes have self canonicals and are listed in the French sitemap, but sitemap timestamps are fabricated at request/build time. Robots allows French pages. No French-specific redirect rules exist; Next defaults to no trailing slash.
- Literal backslash-n text occurs in generated pages. The repeated related-links block favors four near-identical Excel intents and omits CSV/OCR. One “PDF vers CSV” link on the long Excel page incorrectly points to the generic converter.
- Unsupported claims include universal compatibility, guaranteed accuracy, speed, deletion, unlimited exports and bank/API integrations.
- Root document lang is en; a French subtree language boundary is needed. Root SoftwareApplication pricing schema is shared and requires a separate global audit.
